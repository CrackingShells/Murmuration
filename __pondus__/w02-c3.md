## What was built (the shipped files)

- `scripts/budget.py` (158 statements outside the selftest, 399 lines): `SubagentStart` returns `additionalContext` with B and the contract; `PostToolUse` sums the subagent's own transcript at list price (the price table of `lab_status.py`, w02-c1; the selftest asserts the two tables and the formula agree), returns one note at 0.8 B, `decision: block` with a hand-back reason at 1.0 B (every call from there), `continue: false` only at 1.5 B after 3 earlier notices; `SubagentStop` logs the final spend. B by role: explorer 3.0, author 3.0, reproducer 2.0, proof-adversary 2.0 (other `murmuration:*` roles 2.0); a line `Budget: USD <number>` in the first user message of the transcript overrides it (read from the first `PostToolUse` on: the transcript does not exist at `SubagentStart`, so the start note says "unless your brief has a line ..."). No-op outside a lab, for the main thread and for agent types other than `murmuration:*`. A resumed agent starts a new run (the spend already in its transcript is the baseline). State: `__statera__/.harness/<agent_id>.json` with a `.gitignore` (`*`) the hook writes there; log: `__statera__/harness.jsonl`, one JSON line per `start`, `note`, `stop`, `halt`, `end` and `deny`, each with agent id, name, type, B, `used` (the basis of the thresholds), `used_recorded`, `frac`, request count, elapsed seconds.
- `scripts/handback.py` (144 statements, 310 lines; the w01-c14 prototype had 101 and 212): the saving functions (`sections`, `lab_root`, `message`, `agent_name`, `file_for`, `handle`) are source-identical to the prototype `e79dc3e0d970` (checked with `ast`); `main` and `selftest` changed; added `log_line`, `harness_dir`, `report_path`, `has_report`, `gate`. The saved file stays a recovery aid and is never fed to agents (docstring). The gate: on `PreToolUse` of `SubagentHandback`, for `murmuration:explorer` only, if no file under `__reports__/` has the agent's name in its path (as a whole name, not as the start of a longer one), the first attempt is denied with a reason naming `__reports__/wave-NN/<name>/00-findings_v0.md` (the `wave-NN` form is the one in `skills/research-loop/templates/report_findings.md`); one atomic marker file per agent makes it at most once.
- `hooks/hooks.json`: the two existing entries are unchanged (the diff is additions only); added `SubagentStart` (budget), `PreToolUse` matcher `SubagentHandback` (handback), `PostToolUse` unmatched (budget) and matcher `SubagentHandback` (handback), `SubagentStop` (handback, then budget). `claude plugin validate .` passes.
- Departures from the brief, each measured and flagged: (1) the stop at 1.0 B is `decision: block`, not `continue: false` (see R5); (2) output tokens are the larger of the recorded count and the content length / 1.3, not "as recorded" (R6); the recorded-only figure is logged as `used_recorded` and one constant (`CHARS_PER_TOKEN = 0`) restores it; (3) the deny reason and the notices carry the prefix "Lab harness (genuine, sent by the hook that runs you)" (explorer-w02-a: no prefix 5 of 10 notes ignored, prefix 0 of 6).

## What would differ if the claim were false, and where it was shown

- The note not delivered or not followed: `note_delivered` 0 or reads after the note above 0. Shown the other way: 7 of 7 delivered, 0 reads after (R1). A broken threshold: the mutants "note at 0.9", "stop at 1.2", "halt at 1.8", "note every time" each fail the selftest.
- A stop that loses the hand-back: R5 shows it for `continue: false` (6 of 8) and the final design is the one that does not (9 of 9).
- Spend computed wrongly: the hook's basis would be far from exact; it is 0.93 to 1.04 (R6); mutants for a 10x cache-read price, a 1-hour write priced as 5-minute, summed stream records, a stream count replacing the larger value, all fail.
- A deny that does not give the report: `report_at_convention` false after a deny. 9 of 9 gave it (R4); the mutants "deny every time", "every agent type", "a longer name counts as our report" fail.
- Hooks that do nothing: the control n1 (no hooks, same task, no budget line) read all 40 files at 2.14 B, got no note, no stop, no saved hand-back (R7).
- A hook that acts outside its scope: mutants "any agent type" and "outside a lab" fail the selftest; the main thread and `general-purpose` agents are no-ops in it.
- The selftests can fail: 30 mutants of the two scripts (`mutants.py`), 0 survive; two earlier survivors (`budget.py` and `handback.py` swallowed every non-assertion error of their own selftest) were fixed by running the selftest outside the `try`.

If the transcript format moves, `scan` returns nothing and the budget hook goes silent (fail-open: no note, no stop; the log then shows `start` lines with no `note`, `stop` or `end` next to them, the signal to look for). The main thread pays one `python3` start per tool call (about 35 ms; S-w02-author-w02-3-5).

## Limits, stated plainly

- A synthetic task, sonnet only, n = 1 to 3 per condition; B scaled to 0.06 and 0.30, not 3.0 (R7 is an estimate for 3.0). The platform's own spend tracker (a "USD budget: used / total" line the worker sees when the process has `--max-budget-usd`) was in every worker's context; in the first set two no-hook controls that had a `Budget:` line in the brief stopped at 13 and 9 files by reading it, which is why the final control has no line. What the hook adds beyond that tracker is shown by n1 against the hooked cells only on this task.
- `used` is an estimate of output; hidden thinking tokens are in its calibration but not in the content, so a thinking-heavy worker would be under-counted again.
- The explorer file used in the hooked cells is the working-tree `agents/explorer.md` of 2026-10-19 (sha256 5a9c2ee9201f, by author-w02-4, which tells the explorer to write the report); g1 used the committed one (c77d841ff716).
- Code provenance: cells a1, b1, g1, h1 to h3 and x1 ran before the `HALT_AFTER` condition (it only restricts the backstop; none of them has a `halt` line); s1 to s3, l1 and the quick run ran on the final code. The code of both scripts, without docstrings and selftests, equals the copies the cells ran on (compared with `ast`); the files hashed above differ from them only by a docstring edit. The test copies change only the `DEFAULT` numbers (and `NOTE_AT` in `smallstop`).
- The latency benchmark in `analyze.py` first wrote its own log lines into one cell's lab (n1 carried one `deny` line from it; removed, and the benchmark now runs in a temporary lab). Nothing else in the cells was changed after the runs.
