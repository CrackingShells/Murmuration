Why `-S -I` is safe: the guard imports only `json os re shlex sys` (and `tempfile` inside `--selftest`), all standard library, which `-S` (no `site`) does not hide; it imports no sibling file, which `-I` (no script directory on `sys.path`) would hide; `MURMURATION_GUARD_LOG` is read with `os.environ.get`, and `-I` ignores only `PYTHON*` variables, so the log variable is unaffected (shown live below: one log line under `-I`). Compiling the 415-line script at each start costs 2.2 ms (a bytecode-cached `run_hook.py` start would save at most that); not done, as the brief asks for command strings only.
