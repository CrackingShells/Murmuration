## The rule (`user_words.project_root(event)`; `resume_brief.py` imports it)
1. Start = `cwd` of the first transcript record that carries one (reads at most 200 lines or 1 MiB from the head; skips records without a `cwd`, unparsable lines and relative paths).
2. Only when the transcript yields none (no `transcript_path`, no file yet, empty file, nothing within the limit): the payload `cwd` (process directory if absent).
3. Walk up from the start; at each directory test `__statera__/` first, then stop if it has a `.git` entry (folder or worktree file). Found: that is the lab.
4. Else CLAUDE_PROJECT_DIR itself if it has a `__statera__/`.
5. Else nothing: no file or folder is written.
Ordering is the brief's; the change from w01-c10 is that the payload `cwd` (which follows the Bash tool's `cd`) is consulted only when no session `cwd` exists.

## What the transcript holds at UserPromptSubmit time (MEASURED, headless, run1 and run3, 2.1.302)
| prompt | transcript file on disk | payload cwd |
|:--|:--|:--|
| first of a session (also at SessionStart) | no (`transcript_exists` False) | the start directory |
| second and later | yes; head = 2 `queue-operation` records without `cwd`, then `user` and `attachment` records with the start `cwd` | the live shell directory |
So the first prompt of a headless session has no transcript, and rule step 2 is needed; the head begins with records that carry no `cwd`, so "first record that carries one" is needed. In the Desktop the PI saw hook-time records before the first prompt record, but whether they are on disk at hook time is unknown (CONJECTURE).
Two further headless facts: (a) the platform sets the hook's CLAUDE_PROJECT_DIR to the start directory itself and ignores one set in the launch environment (launch env = main checkout, hook saw the worktree; run1), so the Desktop's value cannot be imitated by the launch environment, only by a prefix in the hook command or by `EnterWorktree`; (b) without `--add-dir` the Bash tool resets a `cd` outside the project and the payload `cwd` never moves (run1 case B), with `--add-dir` it follows (run3 prompt 3: `other`).

## Desktop part (CONJECTURE, strongly supported; not dumped)
- The 09:27 prompt of this session went to main under the CLAUDE_PROJECT_DIR-first rule while the session started in the worktree [source: __statera__/wave-04.md "Item 1"].
- PI, this wave [source: __scrupuli__/wave-04-research-pi.md S-w04-research-pi-3; not re-measured by me]: PreToolUse(Agent) and SubagentStart records, written by scripts that resolve the lab from the payload `cwd` first, landed in the worktree's `harness.jsonl` at 09:34. So the payload `cwd` of those events was the worktree. Together with the landing in main, CLAUDE_PROJECT_DIR = main checkout is the remaining explanation, unless UserPromptSubmit's payload differs from PreToolUse's. Still CONJECTURE: nobody has read the Desktop's hook environment.
- Consequence under that conjecture: with the changed rule the first prompt takes the payload `cwd` (the worktree) and later ones the transcript's first `cwd` (the worktree): both give the worktree. If instead the Desktop's CLAUDE_PROJECT_DIR is the worktree, nothing changes for the worse (rows "headless start in a lab"). The case the change cannot fix: a session whose first recorded `cwd` is the main checkout (a Desktop session that starts in main and enters a worktree later, or `claude --resume` from main of a session started in a worktree) lands in main, exactly as the shipped rule does.

## What would differ if the claim were false
If the rule did not hold, the shipped-versus-changed table would show the same lab in both rows, or the third row (shell moved) would show `other` for the changed scripts, as the w01-c10 arm does; the mutants above show the selftest rejecting each wrong rule. The Desktop explanation would be false if a dumped Desktop UserPromptSubmit showed CLAUDE_PROJECT_DIR = worktree and payload `cwd` = main; the rule would then still write to the worktree (transcript first), which is the intended lab, but the cause stated above would be wrong.

## method
- Full: `python3 -I scripts/user_words.py --selftest; python3 -I scripts/resume_brief.py --selftest` (about 10 s); then for the headless table `python3 -I __instrumenta__/hook_lab_landing_run.py <scratch>/run3 <scripts dir> <arm>` once per arm (`scripts` = changed; a folder holding HEAD 41c75ea's `user_words.py`, `resume_brief.py`, `lab_status.py` = shipped; a folder with a `project_root` that tries the payload `cwd` first = payload-first), outside the repository, with `COLGREP_DATA_DIR` inside the scratch folder; `python3 -I __instrumenta__/hook_cwd_probe_run.py <scratch>/run1 <abs path>/__instrumenta__/hook_payload_dump.py` for the transcript table; timing `python3 -I __instrumenta__/hook_wall_time.py <event.json> 30 <lab dir> <before script> <after script>` (event = UserPromptSubmit with `cwd` in the lab and `transcript_path` pointing to a JSONL as described).
- Quick: the two selftests (they carry the E0 cases and the mutant-sensitive assertions; no network, no model).
- Seeds: none (no sampling; model replies do not matter: the hooks fire on prompts). Cost: headless runs use haiku capped at USD 0.40 per session, one to three turns each, seven sessions in total (run1 A and B; run2, two arms, repeated as run3 because run2 lacked --add-dir and its shell never left the project; run3, three arms); I did not read the spend. Wall time of the full method about 6 minutes. `~/.claude/plugins/installed_plugins.json` md5 8d71e8c0f33b7e927133e7e44194de37 before and after every run.
- Cost of the change: user_words.py 189 changed lines in all (git diff --stat) (about 70 of rule, about 115 of selftest), resume_brief.py 78 changed lines in all (a 3-line rule import, about 60 of selftest); reads at most 1 MiB of the transcript head (a measured +1.5 ms); `scripts/` files depend on each other as `lab_init.py` already does; no new platform dependence beyond the documented `transcript_path` and `cwd` payload fields and the transcript's `cwd` record key, which is an undocumented format [assumption: the key was present in every transcript seen, all 2.1.29x-302; a change of format drops the rule to step 2, then 4].
- Not done: dumping the Desktop's hook; a headless case that starts in main and enters a worktree (EnterWorktree); `lab_init.py`/`lab_status.py` (CLAUDE_PROJECT_DIR first: `/lab` in a Desktop worktree would still write the question to main; not my files).
