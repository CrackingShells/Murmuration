### Dependency and caveats

- The "lower bound" for subagent output is my own measurement (R8) and agrees with explorer-w01-a's factors (x3.8 and x5.9 in output tokens, Sonnet). I did not wait for author-w01-2's parallel work on subagent spend sources; if it finds a per-run source of true output, the `UPLIFT` constants in `lab_spend.py` and the `+` marks go, and nothing else changes.
- Per-agent USD is always an estimate: `cost-state` has no per-agent split. Agent rows add up to 207.89 of 224.85 on the combinatorics project.
- Forked sessions: a message record copied into a fork keeps the original `sessionId`; the prototype charges it to that session, as `cost-state` does, and drops it if that session is not in the lab (`inherited`). The ownership rule is MEASURED on 4 sessions where no message id has two owners (0 of 1601).
- The scan counts every session whose `cwd` is under the repository or one of its worktrees, so probe sessions of the plugin's own build (USD 1.11) appear next to this run's; the "where" table separates them, `--since` filters by start time.
