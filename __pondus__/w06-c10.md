- **Heredoc bodies.** A bypass flag inside a heredoc body is not seen: the platform strips the body from the subcommand text an `if` rule matches, so `python3 - <<'EOF' ... --dangerously-skip-permissions ... - **Title scope.** "Allows edits of the guard itself" means edits that add no bypass word. An Edit that adds a selftest line naming `--dangerously-skip-permissions` to the guard is denied by G4, and so is a `git commit -m` whose text names the flag (the Bash row `*dangerously-skip-permissions*` fires and the script sees it in a non-search command; the v0 mention-only denials).
