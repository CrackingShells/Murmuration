## method

Why the tools fit: Python standard library (the server, brief), headless `claude -p` (the only place the platform runs the hooks), `python3 -I` replay and derivation scripts (exact counting over 197 transcripts).

Build (commits on the branch): e07fad6 server, rows, `handback.run`; 6cfcfee SubagentStart probe, lab_status, runner; 79673b9 outage.py; 1936696 apostrophe fix in the fallback text; fd24ba0 trim; aa5318b fast outage.py; a5e708b PI notice after Agent call. Design: `hooks/hooks.json` has `mcp_tool` rows (`server: plugin:murmuration:hooks`, `tool: hook`, `timeout: 3`, input = `script: budget|handback` and the payload fields as `${field}`), one row where main had one `command` (two on SubagentStop; the rows differ by `script`, so they cannot be merged). `user_words.py` and `resume_brief.py` stay `command`. `hook_server.py` is a stdio MCP server whose `tools/list` is empty (the platform calls an unlisted tool), so no agent request carries it and `agents/research-pi.md` needs no deny (stage 1's m3 control, tool allowed: +64 tokens per worker; here the main-thread request 0 is 27984-34470 and workers 12653-13076 in both arms, interleaved, puzzle 7). State kept by the resident process: none (the budget and hand-back state is on disk under the file lock); code: reloaded when a script's mtime changes, a script that does not load keeps the old code and logs a `hook_fault`; fields: `""` dropped, `tool_input` and `tool_calls` parsed; faults: a handler exception or one over 2.5 s is logged as `hook_fault` and, on PostToolBatch and SubagentStart, told to the agent once per 10 minutes. Designed for the four stage-1 findings: dead server, restart that fails: `outage.py` (a `command` hook, `python3 -S -I`, at SubagentStart, PostToolUse(Agent|Task) and PreToolUse(SubagentHandback)) turns the platform's `hook_non_blocking_error` records into text for the worker and the PI, and `lab_status.py` lists the failures; hung restart: `timeout: 3`; identical inputs: rows differ; SubagentStop once per turn: the same handler as main. Cost of the design: 3 command starts per worker (about 150 ms each here) and about 293 production lines.

Commands (outside the repository, `/private/tmp/murmuration-w06/author-w06-4/`; runs use `CLAUDE_CODE_SHELL=/bin/bash`, `--permission-mode auto`, no `--max-budget-usd`, the plugin as `git archive <commit>` export with `--plugin-dir`):
