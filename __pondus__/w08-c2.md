## What changed, in one paragraph

`handback.py` denies once per agent (marker `__statera__/.harness/<agent_id>.long`, created with `O_EXCL`) a `SubagentHandback` call from `murmuration:explorer`, `author`, `reproducer` or `proof-adversary` whose `tool_input.message` has more than 5,000 characters (Python `len`), with a reason that gives the length, names the file to put the detail in (explorer: its report path; others: the lab path the message already names, else "your report, claim file or puzzle file"), asks for a message of the path, the result in a few lines and what is not covered under 5,000, and says the check happens once. An explorer with no report and an over-long message gets one deny with both causes (`cause: report+long`); each cause is asked once (the report marker `.denied` is unchanged). `hooks/hooks.json` is unchanged: its PreToolUse row for `SubagentHandback` already starts this script (about 29 ms per start, 26 ms for an event it ignores). 

## Result

**N (registered before the build).** MEASURED: 217 hand-backs (112 author, 71 reproducer, 32 explorer, 2 other) of the six PI sessions' workers; length in characters, median [p90, max]: author 3,518 [6,549, 10,337], reproducer 3,765 [5,097, 6,229], explorer 4,480 [15,162, 19,661]; caught at N = 3,000 / 4,000 / 5,000: 149 / 102 / 50 (author 60 / 48 / 28, reproducer 55 / 30 / 9, explorer 32 / 22 / 11) [source: `handbacks.tsv`]. The harness adds a median 1,276 characters of frame around each hand-back in the PI's context [source: `pi_side.tsv`, 183 messages]. N was chosen by a rule fixed in the protocol: the largest value on the grid {1,000 ... 6,000} for which CF1 (the PI keeps the short message only) is at least 50% of that variant's own maximum in all six variants (kept length S in {600, 1,200, 2,000}, worker's re-output of the dropped detail counted or not); the rule gives {4,000, 5,000}, so 5,000. It is the N most robust to the PI opening files, not the one of the largest estimated saving (3,000-3,500).

**What the saving is (ESTIMATE; formulas in `counterfactual_S*.md`).** Over the 180 hand-backs with a PI cost (they cost the PI USD 12.37 over their lives; PI spend USD 144.47): at N = 5,000, 42 are fired; PI saving USD 3.2-4.0 (six variants), worker's extra request and re-output USD 1.2-2.3 (Sonnet list price, the worker's own context), so CF1 net USD 0.9-2.8 (1-2% of PI spend). CF2: if the PI then opens the worker's file (the Result section of the report, the claim headline, the verdict lines, plus one PI request), the net is negative for every N up to 5,000 in every variant (CF2-new, for the fired hand-backs the PI did not open in the past: USD -2.5 to -0.5 at N = 5,000); the net stays positive only while the share of fired hand-backs the PI newly opens is below p* = 0.20-0.62 at N = 5,000 (0.30 in the central variant). In the past the PI opened the file a worker named after 19 of 26 explorer hand-backs, 17 of 90 author and 20 of 61 reproducer ones (median 2,439 characters read), 31% of those N = 5,000 would fire on. So: the gross figure of explorer-w08-d (USD 6.0-10.3 at caps of 1,000-3,000) is mostly eaten by the worker's second request, and its sign under the PI's reading behaviour is not measured here.

- h1 (fires once): 7 of 7 over-long cells with the tool called show exactly one deny line; the marker exists; no second deny. h2 (second is short): 5 of 5 cells where the worker had a file and no instruction against it (explorer 2 of 2, author 3 of 3) came back under N, median 2,680 characters. The two that did not shorten are the two whose brief told the worker otherwise; the check cannot make a worker follow it. h4 (under N untouched): 2 of 2 cells, with the gate on, no deny line and no marker. h5: see below.
- h3 (detail kept): in all 5 shortened cells every ground-truth item of the first message (station, founder, population of each of 14 files, 42 items) is in a file the worker wrote (42 of 42). Not shown: that the deny caused it. In the explorer cell the report already held all 42 items in the worker's Write inputs before its first hand-back (the long message duplicated the report); in the author cells 4-13 items are visible in Write/Edit inputs before the deny and 0-1 after, the others were produced by scripts the worker ran, so their timing relative to the deny is not in the inputs.
- h6, paired net (the registered sign test; the size is not an estimate of the saving). Reading A, the gate-attributable one (the PI-side characters of the first message minus the delivered one, at u = 1.2255e-5 USD per character, minus the worker's requests after its first call re-priced at Sonnet list price from the measured tokens): positive in 5 of 5 shortened cells, USD +0.07 to +0.14 each (the messages are 9.6-19 k characters, longer than the lab's typical fired hand-back of 5-7 k, so the size does not transfer). Reading B, difference of whole cells, gate-on minus gate-off (same files, other model draws; `live_pairs.tsv`): explorer pair USD -0.035 (the gate-on worker made 10 requests against 6, a difference that is not the gate's, and its first message was 9.6 k against 5.2 k), author pair USD +0.058. The registered text says "the worker's extra request ... from the measured usage of the pair" and does not choose between the two; on reading B h6 is not met for the explorer pair.
- h7: one start of `handback.py` through `run_hook.py -S -I`, median of 50 (reported): over-long deny path 29.7 ms, over-long pass path 28.7 ms, short message 28.6 ms, an event of another tool 25.9 ms [source: `offline_time.tsv`; the same script rerun by the quick command while four other jobs ran gave 78-156 ms medians for the same payloads, in the same order, so the figure is a floor, not a constant].

**Failure cases (MEASURED, offline, `offline_cases.tsv`, the hook as `hooks.json` starts it; and the selftest, CHECKED).** 32 single-event cases and one concurrency case, exit 0 in all, stderr empty in all: not JSON, empty stdin, a JSON list or string, `tool_input` missing / a list / a string / null, `message` a number / null / a list / an object / absent / empty, `agent_id` missing or a number, `agent_type` missing / another type / a list, another tool, no `cwd`, no lab, a message of exactly N characters and one of N bytes over (2-byte characters): empty answer, no marker, no log line. A message with a lone surrogate (N + 1) and one of 2 million characters get the deny. The second over-long call of the same agent: empty answer, no marker, no line. 12 concurrent starts of one over-long agent: exactly 1 deny. Explorer with no report and over-long: one deny, two markers, `cause: report+long`.

## What the Rust port (w08-c1) must carry over

1. Constants: `LONG = 5000` and the four role strings; the count is Unicode code points (`chars().count()`), not bytes, and a lone surrogate in the JSON string (the hook accepts it) must either be counted as one character or the event handed to the Python script (doubt resolves to the reference).
2. Two markers per agent in `__statera__/.harness/`, `<agent_id>.denied` (report) and `<agent_id>.long`, each created with `O_CREAT|O_EXCL` by the first caller only (the 12-concurrent-start case). The `.long` marker is claimed before the report check is evaluated and is not given back.
3. The combined deny for an explorer with no report and an over-long message, one answer and one log line with `cause: report+long`, `expected`, `chars`, `limit`; a long-only deny line has `cause: long`, `chars`, `limit` and no `expected`; the report-only line is unchanged (no `cause`). Keys sorted, one `write` of one line, as `log_line`.
4. The deny text (tested by substring in the selftest: the length as `N characters`, the path of the report, `once`, and for a report-only deny `not yet at`; a long-only deny must not contain `not yet at`; a non-explorer message that names no lab path gets `claim file or puzzle file`); and `lab_path_in`: the first match of `(__reports__|__pondus__|__scrupuli__)/[A-Za-z0-9_./@-]*[A-Za-z0-9_]` in the message.
5. No answer, no marker, no line when `tool_input` is not an object, `message` is not a string, the type is not a lab role, `agent_id` is absent or not a string (Python raises on a number and the exception is swallowed), or there is no lab.
6. Unchanged: saving, the PostToolUse and SubagentStop paths, `agent_name`, `has_report`.

## Not covered

- Whether a PI that gets a short message opens the file more often: the one quantity on which the sign of the net depends (p* above). The post-landing check in the protocol measures it from the PI transcript with `w08_c2_pi_side.py`; revert if the share of opened files among fired hand-backs rises by more than 0.20 over the past 31%.
- What the PI needs from a hand-back that is not in the file or in the short message: not measured; h3 checks only that the dropped items are in a file.
- Sonnet workers: the live cells use haiku (`CLAUDE_CODE_SUBAGENT_MODEL=haiku`) with briefs built to give long messages; their compliance with the deny is not evidence for Sonnet workers on real briefs. The worker USD is haiku tokens re-priced at Sonnet list price.
- Default permission mode (no `SubagentHandback` call; a `SubagentStop` block would be another mechanism, SA6) and the Rust binary.
- Outside this scope, one thing that bears on the number: a message-only deliverable (a brief that says "write it in your hand-back") makes the check cost a request with no effect (cells a_nopath_auto, e_repeat_auto); briefs of that shape need `limit` raised or the check skipped.
