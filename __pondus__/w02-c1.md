### Caveats and limits

- Open session: the TOTAL is "at least": no `cost-state`, helper calls missing, subagent output at its start-of-stream value; the figure for this run's PI session (60.38) has no later `cost-state` to be compared with. w01-c3 measured x1.18 to x1.40 for ended sessions; the patched script prints no uplift.
- In `auto` mode every subagent request's last record has no `stop_reason` (w01-c2), so every subagent row of this team carries `+`; the mark is correct and, on this team, uniform. Exact per-run output needs OpenTelemetry (w01-c2 R5), not built here.
- The agent table's USD is a list-price estimate per agent (no per-agent `cost-state`); main thread rows have no `+`; an in-flight message of an open session's main thread is not marked.
- The price table is a constant of the file and ages; an unknown model is left unpriced and counted in a printed line, never guessed.
- The detector and the cost-state check use the sessions of this machine; the transcripts of the open session and the subagent files of the open run grow while the checks run, so only the ended sessions' numbers are stable between runs.
- Closes: "the shipped `/lab-status` spend section cannot find the lab's sessions from a worktree or the main checkout, prints no USD, and counts messages once per file" for this machine and Claude Code 2.1.299 transcripts. Does not close: the spend of sessions whose `cwd` is outside the repository, or the same section on Windows.
