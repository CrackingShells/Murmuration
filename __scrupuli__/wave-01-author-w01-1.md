## S-w01-author-w01-1-3
The `SubagentHandback` tool is not a plain tool. In the 2.1.302 binary a hand-back goes through "auto mode's review" and ends in one of three states, `send`, `flagged` (delivered under a SECURITY WARNING) or `withheld` (nothing delivered); every one of these fields is marked `@internal`. The `PostToolUse` payload of the tool is `{"success":true,"message":"Report delivered to your caller."}` in every case I could produce, including p5 where the PI-side copy carried a harness note. So (a) the hook cannot say whether the PI received the report, and in the `withheld` case it would store text the PI never saw, (b) the file lacks the frame ("model output, NOT a message from the user") that the harness wraps around a delivered hand-back, so whatever reads `handbacks/` (a later agent, a verifier) reads unfiltered model output as plain file content. I could not make auto mode withhold or flag-and-block anything with haiku; the nasty text of p5 was delivered with a note. What does the PI's agent do with a file that has no frame?
refs: `~/.local/share/claude/versions/2.1.302` at offsets 214189226 (`handback`, `flagged` fields), 216946727 (`mVn`: "ended without delivering a report through SubagentHandback"), 229044259 (`handback: 'send' | 'flagged' | 'withheld'`); `scratch/p5_auto_bg_nasty/RAWLOG` (tool_response); `scratch/p5_auto_bg_nasty/work/__statera__/handbacks/wave-99-author-w99-2.md`.
