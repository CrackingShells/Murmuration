# P2 v0: a once-only check on `SubagentHandback` that sends back a hand-back over N characters (registered before the build and the live runs)

registered: 2026-10-24, by author-w08-2, after the past-hand-back measurement below and before any change to `scripts/handback.py` or any live run.
Claim: w08-c2. Branch: `w08-c2-shorthandback`, from 1730b71. Verifier: reproducer-w08-2.
The Rust port of `handback` (w08-c1, author-w08-1) is separate: this protocol changes the Python script and nothing else; the claim lists what the port must carry over.

## The change

In `scripts/handback.py`, the PreToolUse check on `SubagentHandback` (today: an explorer with no report file is denied once) also denies, once per agent, a hand-back whose `tool_input.message` is longer than N = 5000 characters (Python `len` of the string), for the four lab roles (`murmuration:explorer`, `author`, `reproducer`, `proof-adversary`). The reason names the length, asks the agent to write the detail into its file first (explorer: `__reports__/wave-NN/<name>/00-findings_v0.md`; other roles: a path of `__reports__/`, `__pondus__/` or `__scrupuli__/` that its message already names, else a claim or puzzle file) and to call `SubagentHandback` again with the path, the result in a few lines, and what is not covered, under N characters; it says the check happens once. State: a second marker file `__statera__/.harness/<agent_id>.long`, created atomically; the report marker `.denied` is unchanged. One JSON line per deny in `__statera__/harness.jsonl` (`event: deny`, the existing fields, and `cause: "long"` or `"report+long"`, `chars`, `limit`). A malformed event, a message that is not a string, an agent of another type, no lab, and any exception: no output, exit 0, as today. `hooks/hooks.json`: the existing PreToolUse row of `SubagentHandback` already starts this script; it changes only if a live run shows it must.

## Past hand-backs, before choosing N (open item 27: outcomes and signs, not sizes read from unpaired medians)

Data [source: `__reports__/wave-08/author-w08-2/handbacks.tsv`, `pi_side.tsv`, `sections.tsv`, `counterfactual_S*.tsv`; scripts `__instrumenta__/w08_c2_handbacks.py`, `w08_c2_pi_side.py`, `w08_c2_sections.py`, `w08_c2_counterfactual.py`]: 217 hand-backs by 6 PI sessions' workers (waves 1-8, 183 of them delivered to a PI transcript with a USD cost in explorer-w08-d's items; 180 priced). Length in characters, median [p90]: author 3,518 [6,549] (n 112), reproducer 3,765 [5,097] (71), explorer 4,553 [15,162] (31). Caught at N = 3,000 / 4,000 / 5,000: 149 / 102 / 50 of 217 hand-backs by length alone.

The counterfactual (ESTIMATE; formulas in the `.md` files). Per fired hand-back: the PI saves u x (length - S) with u the PI-context USD per character of that very message (median 1.2e-5) and S the kept length; the worker pays one extra request at its own cache-read price on its context at the hand-back plus the second message and, as an upper bound, a Write of all that was dropped (variant `low`: the detail is already in the file). CF1 = the PI keeps the short message only. CF2 = the PI also opens the worker's file: the Result section (explorer), the claim headline above `method:` (author), the verdict lines (reproducer), plus one PI request at its next-request cache-read USD. Six variants: S in {600, 1,200, 2,000} x {upper bound, `low`}.

Result before the choice: CF1 net over the 180 hand-backs is USD -1.2 to 4.2 at N = 1,000, at most USD 1.6-4.7 near N = 3,000-3,500 and USD 0.9-2.8 at N = 5,000, against USD 12.37 that the 180 cost the PI over their lives and USD 144 of PI spend (1-2%): the gross saving of explorer-w08-d (USD 6.0-10.3) is mostly eaten by the worker's extra request and re-output. CF2-new (the PI opens the file after the hand-backs it did not open in the past; it opened 31% of the ones that N = 5,000 fires) is negative at every N up to 5,000 in every variant (USD -2.5 to -0.5 at N = 5,000): the net is positive only if the PI newly opens the file in fewer than p* of the fired cases, p* = 0.20-0.62 at N = 5,000 (-0.02 to 0.28 at N = 2,000). So whether a short message saves anything depends on a PI behaviour that no worker-side test measures.

## Choosing N (rule fixed here, applied to the table above)

N is the largest value on the grid {1,000, 1,500, 2,000, 2,500, 3,000, 3,500, 4,000, 5,000, 6,000} for which CF1 is at least 50% of that variant's own maximum over the grid in all six variants. The rule gives {4,000, 5,000}; N = 5,000. Why the largest: p* grows with N (more of the benefit per fired hand-back, fewer fired), so the largest N that still keeps half the best CF1 is the one most robust to the PI newly opening files. N = 5,000 fires on 50 of 217 hand-backs (7 of 23 PI-priced explorer ones, 25 of 95 authors', 9 of 61 reproducers'). The claim states this N is chosen for robustness, not for the largest estimated saving (N = 3,000-3,500).

## Metrics and rule (live and offline; all exact outcomes except h6's USD)

Live cells: headless `claude -p`, parent on haiku, workers on haiku (`CLAUDE_CODE_SUBAGENT_MODEL=haiku`), `CLAUDE_CODE_SHELL=/bin/bash`, no `--max-budget-usd`, permission mode auto or default only, run under `/private/tmp/murmuration-w08/author-w08-2/`, a plugin export of the branch (agents, skills, scripts, and the handback rows of `hooks/hooks.json` only: no Bash guard, whose binary needs the plugin data folder). Gate off = the export of the parent commit's `handback.py`.

- **h1 (fires once):** an explorer cell with a task whose natural hand-back is over N: the first `SubagentHandback` call is denied with the length reason; the second is accepted; `harness.jsonl` has one `deny` line with `cause` `long` (or `report+long`) for that agent; the marker exists. An author-role cell likewise.
- **h2 (second is short):** in the cells above the second message is under N; reported as n of n.
- **h3 (detail kept):** every ground-truth item that the first message held (station name and year of each file) is present in a file the worker wrote before its second call. Exact count.
- **h4 (under N untouched):** a short-task cell: no deny line, no `.long` marker, one hand-back, its recorded text equal to the tool input (sha).
- **h5 (failure cases):** offline, through `run_hook.py -S -I handback` as `hooks.json` starts it: a malformed event (not JSON, a JSON list, `tool_input` a list or a string or missing, `message` a number or null or a list), a message of exactly N and N + 1 characters, an agent of another type, no `agent_id`, no lab: exit 0, stdout empty or one valid deny JSON, nothing on stderr; 12 concurrent starts of one over-long agent: exactly one deny. Live: a worker told to resend the same long message after a deny: the second call passes (the check happens once); a worker with no file path in its brief: the deny names a default file and the second call passes. The selftest of `handback.py` covers the same and passes.
- **h6 (paired net, live; the sign is gated, the size is reported):** for the explorer pair (gate on, gate off; same brief, same files), the PI-side characters of the hand-back (message length plus the 1,276-character frame the harness adds, median of the lab) fall, and `u x (characters saved)` at the lab median u = 1.2e-5 USD/character, minus the worker's extra request re-priced at Sonnet list price from the measured usage of the pair, is positive. One pair is a sign test of the mechanism, not an estimate of the saving.
- **h7 (cost of the check):** wall time of one PreToolUse start of `handback.py` on an over-long message, an under-N one and no-op event, median of 50 (reported, not gated).

**Landing rule.** h1-h5 pass in every cell, h6's sign is positive, reproducer-w08-2 supports, and the PI accepts the CF1/CF2 table above as the stated size of the saving (USD 0.9-2.8 over a hand-back history of 180, estimated; the sign under CF2 unknown). After landing, the first wave that runs it measures, from the PI transcript with `__instrumenta__/w08_c2_pi_side.py`, the share of fired hand-backs after which the PI opened the named file: if it is more than 0.20 above the share before landing (31%), the change is reverted (`LONG` set above any message), since p* at N = 5,000 is 0.20 in the least tolerant variant. This is a rule on a PI behaviour, not on a size.
