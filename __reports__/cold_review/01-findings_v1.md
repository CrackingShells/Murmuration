# Cold review of the shipped files, round 1

Scope: `agents/*.md`, `skills/**`, `scripts/*.py`, `hooks/hooks.json`, `.claude-plugin/plugin.json`, `README.md`, read as an agent meets them in someone else's research project. The only other file read was `00-findings_v0.md`. Nothing under `__design__/`, `__roadmap__/`, `probes/`, `validation/`, no other report, and no git history was read.

What I ran: the four `--selftest`s (all PASS); `lab_init.py`, `lab_status.py` and `resume_brief.py` on a temporary project under `/private/tmp/claude-501/` (deleted afterwards), with hand-made claim, puzzle and wave files built to probe the parsers; a few direct calls to `lab_status.normalise_verdict` and `claim_state`. I did not run `claude`, so what Claude Code does with `skills:`, `name`, `SendMessage`, `${CLAUDE_PLUGIN_ROOT}` in files read with `Read`, and the `agent` setting stays "unverified". The `Agent` tool I had takes no `name` parameter (as in round 0).

Between rounds the structure changed: `references/files.md` and `references/labels.md` are gone and their content (identifiers, file formats, labels, verdicts, current-label table, author/verifier order) now sits in `skills/research-loop/SKILL.md`. Rows that cited the old files are judged against the new location.

Severity: **blocker** = a cold agent cannot complete a step, or the tooling lies without saying so. **should-fix** = a gap or inconsistency a cold agent will trip on. **nit** = polish.

Tally of round 0 (37 rows): FIXED 20, PARTLY 8, NOT FIXED 9, NO LONGER APPLIES 0.

## What passed

- The four `--selftest`s pass.
- A fresh `/lab` creates the four stores, a filled first wave note (user's sentence quoted, no `closed:` line), `user_words.md` with the question verbatim (quotes, `$HOME`), and `.claude/settings.local.json` with `agent` and the two deny rules. `lab_status.py` and `resume_brief.py` read it without error; a second `/lab` appends only.
- Agent `tools:` lines equal the README table, and every tool a role is told to use is in its list: `SendMessage` for author and verifiers, `WebFetch`/`WebSearch` for the explorer, `Edit`/`Write`/`Bash` for the claim file and commands, `ToolSearch` for deferred MCP tools. The PI inherits everything.
- Verdict vocabularies in `reproducer.md` and `proof-adversary.md` equal `SKILL.md:108-111` and `VERDICTS` in `lab_status.py`.
- Claim, puzzle and wave identifiers in `SKILL.md` match what the parsers accept for names in `a-z 0-9 -`; the label parser ignores a stray `label:` after the head.
- A `## argument` heading inside a claim head does not break the parse of the verdict sections.
- No agent file, skill or reference mentions a past study, review, version or design discussion, apart from N16.
