# Cold review of the shipped files, round 0

Scope: `agents/*.md`, `skills/**`, `scripts/*.py`, `hooks/hooks.json`, `.claude-plugin/plugin.json`, `README.md`, read as an agent meets them in someone else's research project. Nothing under `__reports__/`, `__design__/`, `__roadmap__/`, `probes/`, `validation/` and no git history was read.

What I ran: the four `--selftest`s (all PASS); `lab_init.py` and `lab_status.py` on a temporary project (deleted afterwards), including hand-made `__scrupuli__/`, `__pondus__/` and wave files built to probe the parsers. I did not run `claude`, so everything about how Claude Code treats `skills:`, `name`, `SendMessage` and `${CLAUDE_PLUGIN_ROOT}` is marked "unverified" where it matters.

Severity: **blocker** = a cold agent cannot complete a step, or the tooling lies without saying so. **should-fix** = a gap or inconsistency a cold agent will trip on. **nit** = polish.

## What passed

- All four `--selftest`s pass.
- `lab_init.py` on an empty folder creates the four stores, a filled first wave note without a `closed:` line, `user_words.md` with the verbatim question, and settings with the `agent` key and deny rules; a second call appends only. `lab_status.py` and `resume_brief.py` read that fresh lab without error.
- The verdict vocabularies in `reproducer.md` and `proof-adversary.md` equal `labels.md` and the `VERDICTS` table in `lab_status.py`.
- Claim, puzzle and wave identifiers in `files.md` match what the parsers accept for names made of letters, digits, `_` and `-`.
- The README tool table equals the `tools:` lines of the five agents.
- No agent file or skill refers to a past study, a review or a version, apart from the lines listed under meta.
